# WeatherHub - Live Weather Dashboard

A responsive weather web application built for **CODTECH Full Stack Development Internship - Task 1**.

## Features
- Search weather by city name
- Real-time data from **Open-Meteo** (free & no API key required)
- Beautiful responsive design with Tailwind CSS
- Weather condition icons
- Mobile-friendly

## Technologies Used
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript (Fetch API)
- Open-Meteo Geocoding + Weather API
